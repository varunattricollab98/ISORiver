## 6. Editor Guidance Given (Gutenberg)
- Quick Answer = /quote block, bold only the "Quick Answer:" label.
- Headings = /heading → H2 (sections) / H3 (sub + FAQ questions).
- Images = /image, upload, set ALT TEXT (most important field), Title clean (no typo),
  caption/description optional. Ideal image: 1200px+ wide, PNG, Original aspect ratio, width 100%,
  height blank, center, lightbox ON, compress under ~300KB, meaningful filename.
- Table = /table, 3 cols, header row ON.
- Interlinks = select text, Cmd+K, paste isoriver URL, "open in new tab" OFF (internal). External
  link (e.g. apple.com) = new tab ON.
- Rank Math snippet: Title <=60 with keyword at start + power word ("Easy"), Description <=160 with
  exact keyword, short slug.

## 7. Rank Math Philosophy (IMPORTANT lesson taught)
- Owner asked: "Rank Math pe yakeen kare ya apne par?"

  don't chase 100% by ruining content. Orange score can still rank #1 if content is genuinely good.
