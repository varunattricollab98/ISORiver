# ARTICLE STANDARD (Non-Negotiable) — ISORIVER

Har article isi standard pe likhna hai. Quality = #1 priority.

## 1. HUMAN-WRITTEN & AI-DETECTION-PROOF
- Real conversational tone, personal/experience touches ("I tested this on my Mac...")
- Burstiness — sentence length vary karo (chhote + lambe mix)
- Contractions (don't, it's, you'll), opinion + judgment, casual asides
- **NO AI-cliché words:** delve, furthermore, unlock, seamless, "in today's digital world",
  "navigate the landscape", "it's worth noting", "rest assured", etc.
- **CUT repetition** — isoriver ki purani articles ka #1 flaw: same point 3-4x. Ek baar bolo, aage badho.

## 2. UNIQUE
- Not spun, not copied from competitors. Original angle, original examples.

## 3. GOOGLE-POLICY-SAFE
- NO piracy / "free download of paid software" (Adobe/Office/Windows ISO cracks) = demote + AdSense risk.
- Focus: HOW-TO / troubleshooting / legitimate guides.
- No fake "Download Now" buttons on guide articles (remove theme's auto one).

## 4. SEO
- Target exact keyword from SEMrush data. Weave short + long-tail naturally.
- Version-specific for freshness (Windows 11 25H2, macOS Tahoe/26, "2026").
- Keyword in: title (start) + one H2 + one image alt + meta description + content start.
- NEVER keyword-stuff for density. Natural = safe.

## 5. GEO (AI Overview / ChatGPT / Perplexity)
- **Quick Answer / TL;DR box** near top (40-60 words, clean extractable definition) — captures
  AI Overview + featured snippet. Use a /quote block.
- Clean extractable definitions, clear H2 questions.
- **Comparison tables** — competitors rarely use them = differentiator + AI cites tables.
- **6-8 FAQs** from People Also Ask / SEMrush Questions.

## 6. E-E-A-T
- Experience-based, accurate, verified steps for the LATEST OS version.

## STRUCTURE (matches isoriver template)
1. Intro — personal/relatable, states what article covers (rephrase their "Let us begin" cliché)
2. Quick Answer box (/quote)
3. (Screenshot near top)
4. Auto-TOC builds itself — DON'T add manual TOC
5. H2/H3 sections with numbered Step 1/Step 2 instructions + screenshots + tips
6. Comparison table
7. FAQs (H3 question + paragraph answer)
8. Conclusion (put keyword in this H2)

## DELIVERABLES per article (paste-ready)
- SEO Title (<=60, keyword at start + power word), Meta Description (<=160, exact keyword),
  Focus Keyword, URL slug (short), Category
- Full body (H2/H3, steps, table, FAQs)
- [SCREENSHOT X: what to capture] markers + ready alt text for each
- 2-4 internal links (descriptive anchor, same-tab) to related isoriver posts
- Featured image alt suggestion

## INTERLINKING
- Link each article to 2-4 related existing isoriver posts (same cluster).
- Build topical clusters: Windows errors, macOS fixes, emulators/VM, performance/CPU, downloads.
- Internal links = same tab (open in new tab OFF). External authority links = new tab ON.
