# ISORIVER.com — SEO & GEO Content Command Center

Ye repo isoriver.com ke content, SEO/GEO strategy, keyword research aur article backups ka
permanent record hai. Isoriver ek WordPress + Rank Math site hai (live 2019 se), Git pe nahi
chalti — ye repo sirf backup + planning + memory ke liye hai.

---

## 🎯 GOAL (owner ka sole purpose)
Isoriver ko Google pe RANK karwaana + organic US traffic (clicks) laana.
High-quality, human-written, AI-detection-proof, Google-policy-safe, unique articles.

## 👥 ROLES
- **Owner (Varun):** SEO seekh raha hai. SEMrush data deta hai (paid membership). Article WordPress
  mein copy-paste + publish karta hai. Screenshots khud leta hai (Mac/PC se). GSC indexing karta hai.
  Beginner hai — precise step-by-step editor guidance chahiye. Hinglish ("bhai" tone) mein baat.
- **Agent (Kiro / me):** Dedicated SEO+GEO content writer/strategist. Strategy DECIDE karta hoon,
  keyword pick, full paste-ready article likhta hoon, screenshot markers + alt text + Rank Math
  fields + interlinking deta hoon. Editor mein block-by-block guide karta hoon.

## 📁 REPO STRUCTURE
- `README.md` — ye file (overview)

- `keywords-research/` — SEMrush keyword data + topic ideas + winnable analysis

## ⚡ QUICK WORKFLOW (har article)
1. Owner SEMrush data (Overview + Magic Tool + Questions) TEXT mein paste karta hai
2. Agent strategy pick karke full article likhta hai (screenshot markers + alt + meta + interlinks)
3. Owner WordPress Gutenberg editor mein block-by-block paste karta hai
4. Screenshots khud leta hai (Cmd+Shift+4), alt text daalta hai
5. Rank Math fields set (title/desc/slug/focus keyword), score 80+ target (100 ke peeche mat bhaago)
6. Publish → GSC Request Indexing

## 🌐 SITE FACTS
- Platform: WordPress + Rank Math SEO
- Live since: 2019 (old domain = trust advantage)
- Niche: Windows / Mac / Linux OS + software + HOW-TO / troubleshooting guides
- ~500+ posts, ~250+ categories (many thin = SEO liability), target audience = USA
- Auto-generates a Table of Contents from H2/H3 (DON'T add manual TOC — creates duplicate)
- Theme auto-adds a "Download Now" button + download text at post end — REMOVE it on
  how-to/guide articles (misleading, no file to download; likely a per-post Download URL meta field)
